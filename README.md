# Computer Vision Learning Repository

Welcome to my Computer Vision journey! 🚀

This repository is a collection of projects, scripts, and experiments I've built while teaching myself Computer Vision. It serves as my personal playground for learning, practicing, and exploring various computer vision techniques and libraries.

## 🛠️ Tech Stack & Libraries
Throughout these projects, I am primarily exploring and utilizing the following tools:
- **Python**: The core language for these projects.
- **OpenCV (`cv2`)**: Used for image processing, camera capture, and core computer vision tasks.
- **NumPy**: Essential for fast mathematical operations and handling image arrays.
- **cvzone & MediaPipe**: For advanced AI tracking like hand, face, and pose landmarks.
- **Scikit-Learn / Scikit-Image**: For traditional machine learning and advanced image processing tasks.

## 📂 Project Structure
As I continue to learn, I am organizing my code into different folders based on the topic or specific mini-project:

- `color_detection/`: Scripts and tools to track, mask, and identify specific colors within an image or live video feed.
- *(More projects like virtual drag-and-drop, image classification, and text detection will be added as I learn!)*

## 🚀 How to Use
Each sub-project typically contains its own `main.py` script. To run any of the projects:

1. Make sure you have the necessary dependencies installed (you can usually find a `requirements.txt` in the sub-folders).
   ```bash
   pip install opencv-python numpy
   ```
2. Navigate into the specific project directory.
3. Run the Python script!
